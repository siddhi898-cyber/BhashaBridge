# BhashaBridge
BhashaBridge is an offline, AI-powered learning platform built to support mother-tongue-based primary education in rural and low-connectivity communities. It helps bridge the gap between the language children speak at home and the formal language used in school textbooks by translating and simplifying lessons into their preferred local language or dialect. The platform includes speech-to-text, dialect detection, culturally familiar explanations, quizzes, and role-based interfaces for teachers, students, and parents. Developed for Smart India Hackathon 2026, BhashaBridge aims to make foundational learning more accessible, inclusive, and effective—so no child is left behind because of a language barrier.(PS NUMBER-SIH26219)
